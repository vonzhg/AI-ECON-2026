# Knowledge Index

This portable demo contains one local knowledge domain:

- `olg/`
  - Purpose: source material and retrieval guidance for Spear and Young's markdown manuscript on overlapping generations models.
  - Use for questions about OLG, ILA, Samuelson, Diamond, Lucas, Barro, stochastic OLG, the dominance of ILA models, and textbook coverage of OLG.

Do not depend on the original source path. The paper has been copied into this folder at:

- `data/source/Spear-Young_OLG_final_preprint.md`

Generated retrieval artifacts live in:

- `build/chunks.json`
- `build/tfidf_index.json`
