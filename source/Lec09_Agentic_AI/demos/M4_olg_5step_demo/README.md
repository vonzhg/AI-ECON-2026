# OLG 5-Step Workflow Demo

Classroom demo for **Module 4, Topic 4.3** of the Mini-Course (`Slides/Module4_Agentic_AI/M4_T3_Case_DynamicMacro.tex`). Shows the slide deck's five-stage Claude Code workflow in motion, evolving a small overlapping-generations economy from a transparent neural-network seed (V0) into a research-grade two-asset OLG with stabilising homotopy (V5).

## Run path

From this folder:

```bash
pip install -e .
jupyter notebook demo.ipynb
```

Run All. The notebook walks Sections 0 → 7 (V0 → V5), printing each version's validation gate and comparing artifacts across versions.

## What this demo teaches

The lesson is the **workflow**, not the model. Each version transition `V_n → V_{n+1}` is one Claude Code session driven by the literal prompt at `prompts/v{n}_to_v{n+1}.md`, organised by Stages 1–5 (Model → Equilibrium → Algorithm → Pseudo-code → Implement). The artifacts under `versions/` are the evidence the workflow produces validated, version-by-version code.

## Version ladder

Each version is one disciplined extension of the previous. Every transition is justified, validated, and audited.

| Ver | Adds | Validation gate |
|---|---|---|
| **V0** | 3 cohorts, 1 asset, 2-state Markov TFP, single MLP, Euler-residual loss on a cloud of 512 economies | deterministic-SS collapse + procyclical capital + RMS Euler residual < 8% |
| **V1** | 7 cohorts with hump-shaped lifecycle labour; period discount $\beta_y^{72/7}$ | deterministic-SS still collapses + middle-aged consumption peak |
| **V2** | 4-state Markov TFP (Rouwenhorst discretisation of an annual AR(1)) | collapsing TFP back to two states reproduces V1 within 1e-3 |
| **V3** | Second asset (bonds) with endogenous price; market-clearing layer; Fischer–Burmeister complementarity for non-negativity | bond-loss weight zero reproduces V2; positive bond holdings late in life |
| **V4** | Capital adjustment cost $\frac{\psi_K}{2}(a_{K,t+1}-a_{K,t})^2$ | $\psi_K=0$ reproduces V3; capital path smoother |
| **V5** | Four-phase stabilising homotopy: capital-only → bond pretraining → bond homotopy → fine-tuning | per-phase residuals monotone-decreasing; final RMS Euler < 5% |

V5 reaches the *algorithmic structure* of the research-grade target described in `reference/research_target_notes.md`. Going beyond V5 (more cohorts, continuous TFP via Gauss–Hermite, GPU-accelerated array libraries) is a separate engineering project, not the workflow.

## Dependencies

`numpy`, `torch`, `matplotlib`. Install with `pip install -e .`. The notebook prints a one-line environment check in Section 0 and skips any cell whose dependency is missing.

## Slide alignment

The slide deck's running example is an Aiyagari V0 → V2 progression in a four-hour session. This demo applies the same five-stage workflow to a more ambitious target — a six-version climb from a 3-cohort one-asset NN policy to a two-asset NN with stabilising homotopy. Each `prompts/v{n}_to_v{n+1}.md` file is the literal prompt the instructor (or a student) pastes into Claude Code to run that transition's session.
