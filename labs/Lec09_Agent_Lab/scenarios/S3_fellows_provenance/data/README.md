# Data

`pilot_batch_audit.csv` is built from the instructor's pilot batch for the Lecture 10 Econometric Society Fellows exercise (Exercise 10): ten current Fellows, coded only from official and institutional profile pages, with a source URL per extracted field. It holds public professional information.

For this scenario, a few provenance fields in this copy were altered on purpose. No personal attribute was invented: every value that appears is the one the pilot batch recorded. The unaltered batch stays in the Lecture 10 exercise bundle; the list of changes is in `instructor/`, not here.
