# 第12章配套代码：强化学习基础

本目录提供第12章《强化学习基础》的最小可运行示例，目标是把"经济模型 → MDP环境 → 表格型 MC 评估/控制"这条路径跑通，并生成正文贯穿案例的全部数值。

## 依赖

- Python 3.10+
- numpy
- matplotlib（仅 mc_prediction.py 的收敛曲线可选）

（不依赖 gymnasium / pytorch；代码使用表格化与显式循环，便于理解与复现。）

## 文件说明

- `growth_mdp.py`：离散增长模型 MDP（状态 `(k_idx, z_idx)`，行动为下一期资本 `k'` 的索引）。提供 `reset/step` 接口、动作掩码、及作为参考的 `value_iteration`（值函数迭代）。**对应编程练习 (a)**。
- `mc_prediction.py`：首次访问 Monte Carlo 策略评估。给定一个固定策略 `g`，估计 `V^g`，并与 DP 解对比。**对应编程练习 (b)**。
- `mc_control.py`：MC 控制——同时实现"探索性起点" (`mc_control_es`) 和"ε-贪心" (`mc_control_eps_greedy`)，在 20×2 默认网格上与值函数迭代的最优策略对比。**对应编程练习 (c) 与 (d)**。
- `running_example.py`：**正文贯穿案例**（7×2 网格）的全部数值与图坐标。
  - E0：校准、`Q*` 表（表“离散增长模型的 Q*(s,a) 表”）、最优与次优行动的差距、单条轨迹回报的标准差；
  - E1：单个格点上的贪心改进——初始估计精确/粗糙 × 纯贪心/全面采样/定期复查/随机复查（§“广义策略迭代与贪心改进”示例框及其图）；
  - E2：全模型上的纯贪心、探索性起点、ε=0.1 与 ε=1/√n 的首次访问 MC 控制，20 个种子、6000 回合（§“MC 控制”示例框及其图）；
  - E3：最优 ε-软策略的福利代价，以及 on-policy 与普通/加权重要性采样 off-policy 估计的比较（§“On-policy 与 off-policy 方法”示例框及其表）；
  - E4：同一格点上 ε-贪心与 Boltzmann 探索的选择概率（§“探索与开发”）。
  **正文示例框中的每个数字都由该脚本打印；改动脚本后必须同步修改正文。** **对应编程练习 (e)**。

## 快速运行

在项目根目录执行：

```bash
python3 -B code/ch12/growth_mdp.py        # 烟雾测试 + DP 参考解
python3 -B code/ch12/mc_prediction.py     # 首次访问 MC 评估
python3 -B code/ch12/mc_control.py        # MC 控制（ES vs ε-贪心），约 40 秒
python3 -B code/ch12/running_example.py   # 正文贯穿案例 E0–E4，约 2.5 分钟
python3 -B code/ch12/running_example.py --quick   # 缩减重复次数的快速版（数字与正文不同，仅用于调试）
```

`mc_control.py` 会打印量级诊断、ES 与 ε-贪心两条收敛轨迹，以及以价值损失为主的最终评估。它因本环境大量近似并列的 `Q` 值而报告偏高的原始 argmax 不匹配率，评估应以价值损失为准。

## 说明

- 轨迹使用固定长度截断来近似无穷期贴现问题。`running_example.py` 截断在 300 期、首次访问只使用前 150 期出发的回报，被省略的尾部不超过 0.003；其余脚本默认截断在 100 期且不补尾值。
- 所有随机性由固定种子初始化，重复运行输出一致。
- 这些实现以"可读、可改"为第一目标，不追求工业级性能或最优超参数。
