# 第13章配套代码：强化学习核心算法

本目录把第13章的算法放在第12章的离散增长模型上运行，并逐一与动态规划（值函数迭代）的精确解对照：学到的策略在多少个状态上与最优策略 g* 相同，福利损失（消费等价损失 ℓ_CE）有多大。所有脚本固定随机种子，重复运行输出相同（只有“用时 x 秒”随机器变化）；默认不写任何文件，结果打印到标准输出。

## 依赖

- Python 3.9 及以上，numpy。
- pytorch：只有 `dqn_growth.py`、`policy_gradient.py`、`portfolio_ac.py` 需要，CPU 单线程即可。
- `growth_env.py` 按相对路径导入 `code/ch12/growth_mdp.py`，两个目录须保持书稿中的相对位置；导入时不会在 `code/ch12/` 下写 `__pycache__`。

## 文件说明

- `growth_env.py`：本章共用环境。包装第12章的 `DiscreteGrowthMDP`，网格与参数取自第12章 `make_default_env`（练习环境：资本网格 20 点、z∈{0.9, 1.1}、切换概率 0.2、f(k)=k^0.36、δ=0.10、γ=0.95、u=ln c），不重新定义模型。`GrowthEnv.step` 返回 `terminated` 与 `truncated` 两个标志；`BatchGrowthEnv` 把若干独立副本向量化推进；`GrowthBenchmark` 给出 V*、Q*、g*、任意确定性或随机策略的精确价值、ℓ_CE 与平稳分布，只用于评估。
- `running_example.py`：第13章贯穿案例 E5–E9 的数字契约：沿用第12章 7×2 模型（从 `code/ch12/running_example.py` 导入模型与精确解），正文示例框中的数字与图坐标都由它打印；只依赖 numpy。
- `tabular_td_control.py`：§13.2（`sec:ch13_eval_control`）表格型 SARSA 与 Q学习。ε=0.1 的 ε-贪心行为策略，每个状态—行动对步长 C(s,a)^-0.6，带掩码 argmax；3 个种子各 100 万步，与 g* 及最优 ε-软策略（固定 ε 时 SARSA 的理论极限）对照。
- `linear_td_approx.py`：§13.3.1（`subsec:ch13_linear_fa`）线性函数逼近。评估 g* 上 ε=0.1 的 ε-贪心策略 g_ε，基函数 (1, k̃, k̃², 1{z=z_H}, k̃·1{z=z_H})；打印按平稳分布加权的最佳线性拟合误差、TD 不动点及其误差、同一条 100 万期样本路径上的 LSTD 与半梯度 TD(0)。
- `dqn_growth.py`：§13.3.2（`subsec:ch13_nn_dqn`）最小 DQN：经验回放、目标网络、动作掩码；ε 在前一半训练步内衰减完，学习率线性衰减；与 g* 及真正的均匀随机策略对照。
- `policy_gradient.py`：§13.4（`sec:ch13_pg`）带基线的 REINFORCE（按策略梯度定理乘 γ^t，可用 `--reinforce-no-gamma-t` 关掉）与 §13.5（`sec:ch13_ac`）一步演员—评论家。策略是以 (k̃, z̃, k̃') 为输入的打分网络加带掩码 softmax。简化版 PPO 为选读（`--ppo`），正文 §13.5.3（`sec:ch13_ppo`）只作一段概述、不引用其代码。
- `portfolio_ac.py`：§13.8.3 练习题材料，承接第12章练习 4(d)：风险资产份额 ω 的 Beta 策略与 sigmoid-高斯策略，得分函数梯度加评论家基线。回报独立同分布、CRRA 效用下最优份额是短视的，问题对 ω 实际上是静态的；ω*≈0.672 由 Gauss–Hermite 积分求出，作为基准。

在书稿目录（`面向经济学家的人工智能/`）下执行；在 `code/ch13/` 内执行时去掉路径前缀即可。

## 评估口径

- g* 是值函数迭代的最优策略；“与 g* 相同”按 40 个状态逐格比较。本模型最优与次优 k' 的 Q* 差距中位数只有约 0.018，差一格的选择往往几乎不损失福利，所以同时报告福利损失。
- ℓ_CE(s) = exp{(1−γ)[V*(s) − V^g(s)]} − 1：对数效用下，要让按 g 行动的经济与按 g* 行动的经济一样好，永久消费需要提高的比例。V^g 由线性方程组精确求出，不是模拟估计。
- “全部”指 40 个状态的简单平均；“加权”指按 g* 上 ε=0.1 的 ε-贪心策略的平稳分布加权（与 `running_example.py` 的口径一致）。
- 两个参照：均匀随机策略 ℓ_CE 全部 107.08%、加权 109.31%；g* 上 ε=0.1 的 ε-贪心策略本身 12.21% / 12.41%。

## 截断不等于终止

增长模型是无穷期问题，没有终止状态。模拟时每段轨迹在第 T 期被人为截断（`truncated=True`），只是为了换一个起点，并不意味着第 T 期以后价值为零。因此本目录所有自举的算法都把目标写成 r + γ(1 − terminated)·V̂(s')：只有真正的终止（`terminated=True`，本模型从不出现）才去掉自举项，截断时照常自举。若把截断当作终止，等于假定经济在第 T 期之后什么都不值，会低估储蓄的价值。截断照常自举以后，段长只影响起点多久更换一次：`policy_gradient.py` 的演员—评论家用 20 期一段，比 100 期一段学得好得多。REINFORCE 本身不自举，它的截断回报确实丢掉了尾部（在 γ^t 加权下权重为 γ^T≈0.006），用价值估计承担这条尾部正是 §13.5 演员—评论家方法的出发点。
